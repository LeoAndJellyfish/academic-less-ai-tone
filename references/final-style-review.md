# 成稿表达审读

用于初次内容与句群改写完成后的第二遍审读。以下线索帮助识别具体问题；每处删改仍核对有效信息、体裁及上下文。正文顺畅且命题准确的语句保留。

| 待审现象 | 具体判断 | 编辑动作与保留条件 |
| --- | --- | --- |
| 先设误解再纠正，或相邻句持续排除 | 被排除观点是否实际出现；正面陈述是否已覆盖有效含义 | 虚设部分删去，直陈有据判断；真实争论、定义区分和统计限定保留其关系 |
| “一句话、核心是、值得注意”等提示壳 | 删除提示后信息与衔接是否完整 | 直接写具体判断；必要的来源、范围和承接信息继续表达 |
| 每段先报流程、再作抽象总结 | 当前句是否增加问题、证据或解释 | 沿同一问题续写；章节导入、长段后的必要回顾依理解需要保留 |
| 概括遮盖已有细节 | 同段或相邻资料是否给出相应数字、时间和对象 | 恢复有效细节，核对口径；缺资料时列具体缺项 |
| 相邻句反复使用同一骨架 | 读者是否持续读到标签和套式，关系却不清楚 | 按当前问题重写句群；并列步骤、条款、引语和有意排比保留功能 |
| 罗列和长修饰增加理解负担 | 每项是否提供独立且必要的信息 | 按对象与动作组织完整句群；变量、配置项及专业限定逐项保存 |
| 揭晓式标点和反复分层 | 冒号、破折号是否替代了具体说明或连续承担同一停顿 | 写完整句子；引语、定义、表格、代码及规范标点按用途保留 |
| 生造口语、理想化拟人、口头禅 | 说法是否解释机制，是否符合讲者和听众 | 采用具体动作或结果；有解释作用且边界清楚的比喻、自然设问可留 |
| 长定语、含混话题壳、空泛回指 | 对象、条件和谓语是否容易确定 | 展开修饰，明确主语及范围；必要的书面表达和逻辑词按功能保留 |

句长、段长、连接词、问句或三项并列本身均按语境判断。编号承担章节、步骤或交叉引用功能时保留。用户另有禁用清单时逐项遵守。

## 成对示例

**已有数据承担判断。**给定同一评价条件下漏检减少208条、误报增加61条：

> 原句：一句话：它变得更爱报警了。
>
> 修订：漏检减少208条，误报增加61条。

两项变化均保留。若本段负责解释决策，再接续相应成本或复核安排，资料不足时采用建议语气。

**自然讲述需要问题推进。**教学资料给出训练、验证、测试的三类用途：

> 原稿：我们不是简单地切分数据，而是在构建一个严谨可靠的评价闭环。训练集用于训练，验证集用于验证，测试集用于测试。
>
> 修订：模型先在训练集上学习。参数怎样选，需要在验证集上比较。方法和参数确定以后，再在测试集上评价最终表现。

依题中设定解释三类数据的作用。项目实际划分和使用不同，按实现核对。

**清楚的原句少改。**

> 这两条标题都以and结尾，为什么只有一条被标为异常？

若随后材料确实解释两者差异，设问承担判断任务，可原样保留。操作定义、完整配置列表、直接引语及必要限定同样按其实际作用保留。

**删去完整的无据经历。**资料只给出实验条件与结果，原句却写“去年我带队反复试验后才发现这个规律”。人称、带队经历、时间与发现过程均属待审主张。修订从给定实验条件和结果展开；仅替换“我带队”或“才发现”仍会留下无据经历。附注中的删改说明随实际正文核验。

**数值的解释尺度依资料。**资料给出回归系数0.12和置信区间，尚无变量变换与模型形式。正文按资料报告系数与区间，保留已给解释。将其解释为“每增加一个单位，结果平均增加0.12个单位”引入了额外的模型尺度假设。

## 最后连读

逐段检查读者能否回答当前问题、依据是什么、结论到哪里。再连读相邻两段，检查新对象、新术语和新方法为何出现。发现残留问题后修订对应句群，再从必留清单核对信息。最终说明采用实际完成的检查名称，书面审读、模型试写与真人评价分别登记。
